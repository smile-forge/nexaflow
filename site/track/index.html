Keep track

Somewhere to put the state that usually lives in your head.

A product tree that tracks status across a codebase and binds each node to the code that implements it, so "is this done" has an answer you can check. Lightweight project folders with a backlog. A corkboard you can drop files, links, pictures and half-formed thoughts onto.

None of it is a service and none of it is in the cloud. It is files beside your work.
