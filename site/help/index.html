These pages describe Nexaflow as it stands after v1.6.0, so some of what they cover is not in the current download yet. The latest release is v1.6.0.

Reference

Every help page Nexaflow ships — the same text the app shows beside what you are working on. Press F1 in the app to read it there instead.

Open anything

3D Model viewer

Opens a 3D model file and lets you turn it, and says what the file holds.

Archive inspector

Lists what is inside an archive, and lets you read, test, extract, repack, encrypt and sign it.

Audio player

Plays audio files, shows the waveform and lyrics, and edits the track's tags.

Code editor

Shows a source file with syntax colouring and an outline of its structure, and lets you edit and save it.

DICOM viewer

Opens a DICOM study, scrolls through its images, measures them and lists their tags. It only reads, so nothing on the disc changes.

Email viewer

Opens a saved .eml or Outlook .msg file and shows the message, its headers and its attachments. It reads only: there is no send, reply or forward…

Executable Inspector

Shows what is inside a Windows .exe, .dll or .sys file and how it was signed.

File System

Browses the drives and folders on this PC and acts on the files in them.

Font viewer

Sets your own text in several fonts at once, and shows what each font contains.

Hex Editor

Shows the bytes in a file and lets you change them.

Images

Opens one picture, a selection, or every picture in a folder.

JSON viewer

Shows a JSON file as a tree you can read, edit and search.

Log viewer

Reads a log file, starting at the newest lines, and keeps up as the file grows. Nothing here writes to the file.

Notebook

Opens a Jupyter notebook and shows its cells in order as a page you can read.

PDF reader

Shows a PDF's pages, and lists what the document records about itself.

Search

Finds files by name or by what is inside them, using the Windows Search index.

SVG viewer

Shows an SVG drawing and lets you zoom into it without it going soft.

Tabular

Opens a delimited text file as a grid. Nothing you do here writes to the file.

Text viewer

Opens a text file of any size, and can search it, edit it and split it into smaller files.

Video player

Plays a video file in a tab.

Virtual Disk

Shows what is inside a disk image — its volumes and the files they hold — without writing to it.

Web browser

Opens web pages and local HTML files in a tab.

Author & draw

Markdown

Nexaflow renders Markdown natively — no browser, no JavaScript, no round-trip to a web view. Open a .md file and you get a fast, scrollable…

Markdown — Chemistry, word clouds & plots

Chemical structures from SMILES, shaped word clouds, and correlation plots over your own data.

Markdown — Diagrams

Twenty-four Mermaid diagram types, drawn natively on the canvas from a fenced block.

Markdown — Diagrams: charts & analysis

Diagrams for proportion, distribution, comparison and cause: pie, XY, radar and quadrant charts, Sankey, Ishikawa, Venn and Cynefin diagrams.

Markdown — Diagrams: flow & structure

Diagrams for how something is built, and how it runs: flowcharts, sequence, class, state and ER diagrams, and the C4 family.

Markdown — Diagrams: planning & time

Diagrams for what happens, in what order, and who it is for: requirements, Gantt charts, git graphs, kanban boards, mindmaps, timelines and user…

Markdown — QR codes & barcodes

Machine-readable codes drawn from a fenced block: QR, linear barcodes, Data Matrix, PDF417 and Aztec.

Solver

Works out a maths problem you type in, and keeps each answer below it.

Run your machine

Console

Runs a Windows command prompt in a tab, and sends anything that isn't a command to the assistant.

Environment Variables

Shows the User and Machine environment variables, and lets you change, add and delete them.

Installed Apps

Lists the applications installed on this PC and lets you remove, modify or repair them.

Network

Lists the devices on your network and what is known about each one.

Process detail

Shows one process — its identity, resource use, threads, modules and open handles.

Processes

Lists the processes running on this machine and lets you inspect or end them.

Registry

The Registry page browses the Windows registry and edits keys and values in it.

Services

Lists the Windows services on this machine and lets you start, stop and reconfigure them.

System Info

Reports what this machine is: its Windows build, hardware, displays, disks and security settings.

Keep track

Graph

Draws the product tree joined to the code its snaplinks reach, and lets you walk it a node at a time.

Integrity

Lists every snaplink whose target no longer exists, and lets you repair each one here.

Product

Tracks a folder's software as a tree of nodes, each with a status, and lets you edit that tree here.

Project

Shows one project's description, completion criteria and backlog, and lets you change them.

Projects

Lists the project folders you keep, and opens one.

Scratchpad

A board of post-it notes you can drop files, links, pictures and text onto.

Search

Lists what a query matched in this product's knowledge graph, and opens each result where it lives.

With your AI

AI Chat

Lists your saved conversations with the assistant, and starts new ones.

Conversation

A saved chat with the assistant that can read and act on the pages you pin to it.

Getting around

Help

Explains the page you are working on, in a pane beside it.
