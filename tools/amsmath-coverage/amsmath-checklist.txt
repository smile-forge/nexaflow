# amsmath constructs, grouped by the section of the user guide that introduces them.
# section | name | sample markup | caveat
#
# A blank sample means the construct is document-level - numbering, page breaks, cross
# references - and has no meaning in a standalone formula, so it is not counted either way.
# A caveat records something that renders but is not faithful: the survey can only see whether
# a formula comes out, not whether it came out right, so anything known to be approximate has
# to be written down here.
