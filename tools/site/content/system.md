# Run your machine

A real terminal, and the tools you would otherwise go hunting for.

A PTY per tab with shell integration, so arrow keys, Ctrl+C and interactive programs behave the way
they should. A live process explorer, services, environment variables, the registry, installed apps,
and an inspector that tells you what an executable actually is.

Elevated work goes through a privilege bridge, so a UAC prompt never arrives in the middle of
something else.
