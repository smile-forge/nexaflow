# Web browser

Opens web pages and local HTML files in a tab.

---

## Opening a page

- Open an HTML file: choose **Browse** on any `.html` or `.htm` file in the File System page.
- Open the address a shortcut points to: open the `.url` file.
- An address handed over by another page, such as a device's published address on the Network page, opens here.
- A page inside an archive or a disk image is unpacked to a temporary copy first, then shown.

## Moving around

Getting about is done from [the toolbar above the page](locate:Web_Back,Web_Address,Web_Reload).

- Click links in the page and they load in this tab.
- Step through the pages you have visited with [Back and Forward](locate:Web_Back,Web_Forward). Each is greyed out until there is somewhere to go.
- Fetch the current page again: [Reload](locate:Web_Reload).
- The address is a label. You cannot type into it.
- Jump to a point of the site: click that part of [the breadcrumb bar](locate:Chrome_BreadcrumbBar), which splits the address into the site and each part of its path.
- The tab is titled with the page's own title, or the last part of the address, or the file name for a local file.

## Your default browser

- Open the address this tab started from in Windows: [Open in your default browser](locate:Web_OpenExternal).
- Only web and file addresses are handed to Windows; anything else is refused with a message.
- If the browser cannot start in this tab, the page area says why and offers the same button, plus a link to install the Microsoft Edge WebView2 runtime when that is what is missing. You are also prompted at once to open the page in your default browser instead.

## The assistant

- It sees a screenshot of the page, not its text or its source.
- It can scroll about three quarters of a screen at a time, down or up.
- It cannot click, type or navigate.
- It knows the address and title of the page, and whether it is still loading.

## Elsewhere in the app

- Pin a site to the ribbon: drag a link out of another browser and drop it on the ribbon. It becomes a button that opens that address here.
- Cookies and sign-ins are kept for your Windows account between sessions.
- Tear the tab into another window and the page keeps its place and its history.
- The page steps aside while an assistant answer or Options covers it, and comes back after.
- Closing the tab shuts its browser down.
