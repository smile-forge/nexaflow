# Security Policy

## Supported versions

Nexaflow follows a rolling release model — fixes land in the latest version.

| Version | Supported |
|---------|-----------|
| 1.x     | ✅ Yes    |
| < 1.0   | ❌ No     |

## Reporting a concern

If you find a security problem in Nexaflow, please let us know by
**[opening an issue](https://github.com/smile-forge/nexaflow/issues)**. Include:

- a clear description of the problem,
- the steps to reproduce it, and
- the version of Nexaflow and your Windows version.

If the issue is sensitive and you'd rather not disclose it publicly, you can
report it privately instead via GitHub's
[private reporting](https://github.com/smile-forge/nexaflow/security/advisories/new)
(**Security → Report a vulnerability**).

We'll review every report, keep you updated on progress, and credit you in the
fix unless you'd prefer to stay anonymous. Thanks for helping keep Nexaflow and
its users safe.
